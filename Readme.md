# CSS Selectors and Styling Assignment

## Description
An HTML and CSS webpage created to practice external stylesheets (`style.css`), element selectors, class and ID selectors, descendant selectors, and styling specific text without using inline CSS, classes, or IDs.

## Features Included
- **External CSS Connection:** Links `style.css` to `index.html` and applies a `skyblue` page background.
- **Headings Styling:** Uses three heading tags (`h1`, `h2`, `h3`) with `.head` class styling (`darkblue`), `#bglime` background highlighting, and targeted red text styling on the word `"head"`.
- **Paragraphs Styling:** Styles three `<p>` elements with white text using only the `p` tag selector, and highlights the word `"paragraph"` in the second line using black text and an increased font size.
- **Lists Styling:** Includes unordered (`<ul>`) and ordered (`<ol>`) lists with targeted styling on the `"here"` link text using structural tag selectors (`ul li a`) without inline CSS, IDs, or classes.

## Files Included
- `index.html` - Main HTML structure and content.
- `style.css` - External stylesheet containing all CSS rules.
- `Readme.md` - Project documentation.

## How to Run Locally
1. Download or unzip the project folder.
2. Ensure `index.html` and `style.css` are in the same directory.
3. Double-click `index.html` to open and view it in any web browser.
